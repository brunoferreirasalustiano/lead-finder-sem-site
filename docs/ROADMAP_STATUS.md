# Governança do roadmap

O roadmap estratégico é direcional. Ele não autoriza automaticamente implementação, contratação de providers, coleta de dados reais, envio de mensagens, compra de infraestrutura ou expansão internacional.

Cada horizonte deve ser convertido em issues menores, com hipótese, escopo, riscos, métricas, critérios de aceite, dependências e evidências. Alterações sensíveis continuam sujeitas aos controles de segurança, privacidade, revisão humana e operação fail-closed definidos no projeto.

## Revisão

O roadmap deve ser revisado após:

- conclusão do primeiro piloto real controlado;
- primeira venda entregue pelo fluxo completo;
- obtenção de receita recorrente;
- entrada em novo canal de comunicação;
- introdução de multi-tenancy;
- contratação do primeiro cliente de médio porte;
- preparação para requisitos enterprise;
- decisão formal de internacionalização.
