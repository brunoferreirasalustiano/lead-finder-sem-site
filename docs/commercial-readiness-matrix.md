# Matriz de prontidão comercial

Shadow mode é observação de dados reais sem contato. Avanço exige nenhum envio/provider/rede de campanha, guard sem bypass, dedupe ≤5%, precisão humana ≥85%, falso positivo ≤15%, contato válido ≥70%, readiness/backup/rollback/relatório PASS e zero incidente crítico. Limiar é hipótese. Percentual é `PASS / critérios aplicáveis × 100`; bloqueador crítico impõe `NO_GO` e impede 100%.
