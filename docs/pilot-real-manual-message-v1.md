# Mensagem comercial manual — piloto real controlado v1

**Estado:** template aprovado para uso manual controlado; nenhum envio automático autorizado.

## Texto-base

> Olá, [NOME]. Sou [REMETENTE], da [EMPRESA]. Estou entrando em contato porque estamos revisando, manualmente, se negócios do segmento [SEGMENTO] na região [REGIÃO] podem ter interesse em uma presença digital mais clara. Não assumimos que essa avaliação esteja correta sem a sua confirmação. Se este assunto não fizer sentido, basta responder que não deseja receber novos contatos e não insistiremos. Se preferir, posso explicar em poucas linhas o motivo deste contato.

Regras do texto: manter a identificação do remetente; explicar o motivo sem alegar fato não confirmado; não usar urgência, pressão ou promessa enganosa; permitir resposta negativa; registrar e respeitar opt-out; enviar somente após revisão humana individual. Este arquivo nunca é uma ordem de envio.
